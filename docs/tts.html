Text-to-Speech

How TTS synthesis works, how to configure it, and how multi-word sentences are handled.

How TTS Works

When a command is triggered and no audio file exists for it, the bot synthesises the word or phrase using pyttsx3 — a Python text-to-speech library that uses Windows' built-in SAPI voices. The synthesised audio is saved to a cache file and played through the virtual audio cable just like a regular audio file.

The cache means that a phrase only needs to be synthesised once — repeated triggers of the same word play the cached file instantly with no synthesis delay.

Single Words vs Sentences

The bot handles single words and multi-word sentences differently for best results:

ScenarioWhat happens
Single word, audio file existsPlays the audio file
Single word, no audio fileSynthesises the word via TTS
Multi-word, all words have filesPlays each file in sequence, Circle held throughout
Multi-word, any word is missing a fileSynthesises the entire sentence as one phrase — sounds natural rather than word-by-word robotic
Multi-word, Always use TTS tickedSynthesises the entire sentence regardless of files
💡

Synthesising a full sentence like "go to the table" as one TTS phrase produces far more natural-sounding speech than synthesising each word individually. The game's voice recognition handles flowing speech better than robotic individual words.

TTS Settings

Enable TTS

When ticked, any command word or phrase that does not have an audio file is synthesised via TTS. If unticked and no audio file exists, the command is silently skipped.

Always Use TTS

Ignores all audio files and synthesises everything. Useful for testing, or if you prefer a consistent TTS voice over a mix of recorded and synthesised audio.

Filter Hateful / Explicit Words

Keeps this ticked. Words on the blocklist are never passed to TTS regardless of any other setting. Chat button trigger words are also automatically excluded from TTS — if you assign "confirm" to Square, typing "confirm" will press Square but will not also be spoken.

TTS Voice

Lists all SAPI voices installed on your Windows system. Click the refresh button (↻) to repopulate the list. Different voices have very different recognition rates with the game — experiment to find what works best. Microsoft Zira and Microsoft David are common Windows defaults.

Speech Rate

Words per minute. Default is 150. Lower values (120–130) produce slower, more deliberate speech that the game may recognise more reliably. Very high values (200+) can cause words to blur together.

Gap Between Words

Controls the pause between individual words when playing multiple audio files in sequence. This does not apply when the whole sentence is synthesised as one TTS phrase.

  • Positive value — inserts a silent pause of that many seconds between words
  • Zero — words play back-to-back with no gap
  • Negative value — trims that many seconds of silence off the end of each audio clip before the next word begins. Useful when your audio files have trailing silence that makes the sentence feel slow.

Improving Recognition

If the game consistently ignores TTS commands, try these in order:

  1. Lower the speech rate to 120–130 wpm
  2. Try a different TTS voice — some voices are clearer to the game's recognition system
  3. Increase the microphone volume in PCSX2's audio settings
  4. Increase the "Pause after press" timing to 0.7s or 1.0s — the game may need more time to start listening
  5. Record your own voice clips for the most frequently used commands — human speech works better than TTS
