Virtual Controller

How the bot presses the Circle button automatically, and how to set up the PS2 button commands for chat.

Why a Virtual Controller?

In Lifeline, holding the Circle button activates the microphone. The game will not listen to mic input unless Circle is being held. The bot creates a virtual PS2-compatible controller and holds Circle for you automatically on every voice command.

Without this, the audio would play through the virtual cable but the game would ignore it because the mic activation button is never pressed.

Installing ViGEmBus

1

Download ViGEmBus

Go to github.com/nefarius/ViGEmBus/releases and download the latest ViGEmBus_Setup_x64.exe.

2

Install it

Run the installer. It will install a kernel driver that Windows uses to recognise virtual controllers.

3

Reboot

You must reboot. The driver is not active until after a restart.

4

Install the Python package

Run pip install vgamepad if you haven't already (it's included in requirements.txt).

Enabling the Controller in the Bot

In the bot, go to ⚙️ Settings → Virtual Controller:

  1. Tick Enable virtual controller
  2. Choose DS4 (PlayStation) — this is what PCSX2 maps most naturally to a PS2 controller. If DS4 fails, try Xbox 360.
  3. Click 💾 Save Settings
  4. The status label should say Virtual DS4 controller created

ℹ️
Circle is always Circle

The microphone button is hardcoded to Circle — this cannot be changed in the settings because it is a fundamental part of how Lifeline works. The other buttons can be triggered from chat as separate commands without any Circle hold.

Assigning in PCSX2

After creating the virtual controller in the bot, you need to tell PCSX2 to use it. See PCSX2 Configuration for the full walkthrough. In short: go to PCSX2 Settings → Controllers and map the virtual controller to Player 1.

Testing the Controller

Click Test Circle timing in the settings panel. This runs through the full press-pause-hold-release sequence without playing any audio. Watch the PCSX2 controller input display to confirm Circle registers.

If the button press does not appear in PCSX2's controller test:

  • Make sure ViGEmBus is installed and you have rebooted
  • Make sure the virtual controller is assigned to Player 1 in PCSX2's controller settings
  • Try switching between DS4 and Xbox 360 mode — PCSX2 may recognise one better than the other
