Installation

How to download, install and launch the bot for the first time.

Step 1 — Download the Bot

Download all files from the GitHub repository and put them in a folder on your PC. You need these four files in the same folder:

lifeline_bot.py       ← the main program
requirements.txt      ← Python package list
run.bat               ← Windows launcher (optional but convenient)
README.md             ← short reference
💡

Put the folder somewhere easy to find, like C:\lifeline-bot\ or your Desktop. Avoid paths with spaces or special characters.

Step 2 — Install Python Packages

Open a Command Prompt or PowerShell window in the folder where you saved the files.

The quickest way: in File Explorer, navigate to the folder, then click the address bar, type cmd and press Enter. A command prompt opens already pointing at that folder.

Then run:

pip install -r requirements.txt

You will see packages downloading and installing. Wait for it to complete. If you see errors about permissions, try:

pip install -r requirements.txt --user

Step 3 — Launch the App

You have two options:

Option A — Double-click run.bat

The easiest way. It checks for Python, installs/updates packages, then launches the bot. A console window stays open alongside the GUI — this is normal, it shows log output.

Option B — Command line

python lifeline_bot.py

The app window will open. You will see three tabs at the top: 🎮 Live Feed, ⚙️ Settings, and 📋 Commands.

Step 4 — First-Time Settings

Before you can connect or use the bot you need to configure it. Go to the ⚙️ Settings tab. Work through each section top to bottom:

1

Twitch IRC

Enter your channel name (no #) and your OAuth token. See Twitch Connection for how to get the token.

2

Audio — Output Device

Set the output device to CABLE Input (VB-Audio Virtual Cable). If this option does not appear, VB-Cable is not installed or you have not rebooted. See Virtual Audio Cable.

3

Virtual Controller

Tick Enable virtual controller. Choose DS4 or Xbox360. If enabling fails, ViGEmBus is not installed. See Virtual Controller.

4

TTS

Tick Enable TTS so words with no audio file are still spoken. Keep the word filter ticked.

5

Save

Click 💾 Save Settings. Settings are written to config.json in the same folder as the bot. They will be restored the next time you launch.

Step 5 — Connect

Go to the 🎮 Live Feed tab and click ▶ Connect. The status indicator turns green and shows ⬤ Live when connected. Chat messages will start appearing in the left panel. Triggered commands appear in the right panel.

✅
Test before going live

Type yes in your Twitch chat (or ask a friend to). You should see it appear in the chat log, highlighted in gold, and the command log should show ▶ yes with a Circle HELD / Circle released pair. If you hear audio through your speakers as well as the cable, your output device is set to the wrong device.

Files Created Automatically

After first use, you will see these new files/folders appear alongside the bot:

File/FolderWhat it is
config.jsonAll your saved settings. Do not edit by hand. If it becomes corrupted, it is automatically backed up as config.json.corrupted.
_tts_cache/Cached TTS audio files. One .wav per word/phrase. Safe to delete if you want to free space — they regenerate on demand.
