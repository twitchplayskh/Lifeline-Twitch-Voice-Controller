Using the Bot

Commands List

Every word and phrase the bot recognises from Twitch chat. Type any of these to send a voice command to the game.

ℹ️

Commands are case-insensitive. GO, Go and go all work. Phrases must match exactly — go back works, going back does not.

How Matching Works

The bot uses two-pass matching on every chat message:

  1. Phrase scan first — scans for the longest matching multi-word phrase. go back fires as one phrase, not as separate go and back commands.
  2. Word scan second — on the remaining text not claimed by a phrase, picks up individual command words.

This means a message like go back and check the door fires: go back (phrase) + check (word) + door (word).

Adding Custom Commands

Go to the 📋 Commands tab in the app and scroll to Custom Commands. Type one word or phrase per line and click ✅ Apply Custom Commands.

  • Single words — added to the word list, matched individually
  • Multi-word entries — treated as phrases, matched as a unit
  • You can then create audio files with the same name, or TTS will handle them automatically
