Using the Bot

Chat Button Commands

Let chat press PS2 buttons directly — for confirming menu selections, opening the map, skipping cutscenes, and more. No Circle hold involved.

What Are Chat Button Commands?

Voice commands always hold Circle because that is how Lifeline's microphone works. But some actions in the game are done with regular PS2 buttons — confirming a selection, cancelling, opening the map, or pausing. These do not use the microphone at all.

Chat button commands let your viewers trigger these buttons by typing a word in chat. When the trigger word appears, the bot presses and immediately releases that button on the virtual controller — no Circle hold, no audio playback, no TTS. It is a direct button press.

Default Button Assignments

PS2 ButtonDefault trigger wordFunction in Lifeline
Square □confirmConfirm selections in menus and conversations
Cross ×cancelCancel / go back in menus
Triangle △analysisShow analysis points or enemy weak spots during battle
L1mapOpen the map
R1itemsShow item list / switch camera view in battles
L2skipSkip events or cutscenes
StartpausePause the game
SelectselectSkip events in some menus

All buttons are off by default. You choose which ones to enable and can change the trigger word for each one.

Enabling Chat Buttons

1

Go to Settings → Virtual Controller → Chat-Triggered Button Commands

Scroll down past the voice timing section. You will see a table with a row for each PS2 button.

2

Tick the "On" checkbox for each button you want active

Only ticked buttons will respond to chat. Leave buttons off if you do not want chat to be able to trigger them — for example you might not want chat to be able to pause the game.

3

Customise the trigger word if needed

Click into the trigger word field and type whatever word you want chat to use. The word does not need to be a Lifeline voice command — it is completely independent. Keep trigger words short and unambiguous.

4

Save Settings

Click 💾 Save Settings. The enabled state and trigger words are saved to config.json and restored on next launch.

⚠️
Trigger words are automatically blocked from TTS

If you assign "confirm" as the Square trigger word, typing "confirm" in chat will press Square — but it will never also be spoken as a voice command. The word filter automatically prevents chat button trigger words from reaching TTS, so there is no risk of a button press accidentally triggering audio as well.

How Trigger Detection Works

Chat button scanning runs independently of the voice command system, at the very top of message processing before any Lifeline command matching happens. This means:

  • The trigger word does not need to be in the Lifeline command list
  • Trigger words fire even if the message contains no voice commands at all
  • Trigger words are matched as whole words — typing maps will not trigger the map button
  • Multi-word triggers are supported — you could set a trigger like open map
  • The bot logs ▶ L1 pressed / ▶ L1 released in the command feed so you can confirm it fired

Tips for Streamer Use

  • Be selective — only enable buttons that are genuinely useful for chat to control. Having too many active buttons creates chaos.
  • Avoid common words as triggers — if you set "yes" as a button trigger, it will press that button every time chat says yes as a voice command. Use distinct words that would not appear naturally in game commands.
  • Consider the pause button carefully — enabling the Start/Pause button means any viewer can pause your game at any time. You may prefer to leave this one off.
  • Announce trigger words to your stream — add the active trigger words to your channel's !commands bot response so viewers know what works.
