Virtual Audio Cable

The most critical piece of the setup. Without this the game will never hear any commands.

🛑
This step is not optional

The game expects a real USB microphone plugged into the PS2. The virtual audio cable tricks PCSX2 into thinking the bot's audio playback IS that microphone. Without it, there is nothing to route audio through and the game receives only silence.

Why a Virtual Audio Cable?

Think of VB-Cable as a virtual pipe with two ends:

  • CABLE Input — anything played to this device comes out the other end
  • CABLE Output — appears to Windows and other apps as a microphone

The bot plays audio to CABLE Input. PCSX2 reads audio from CABLE Output as if it were a real microphone. The game hears the command exactly as it would if someone spoke into a headset.

Installing VB-Cable

1

Download VB-Cable

Go to vb-audio.com/Cable and click the Download button. The download is a zip file containing the installer.

2

Run the installer as Administrator

Extract the zip. Right-click VBCABLE_Setup_x64.exe and choose Run as administrator. Click Install Driver in the dialog. Windows may show a security warning — click Install to continue.

3

Reboot

You must reboot your PC. The driver is not active until after a restart. This is not optional — the devices will not appear in Windows until you reboot.

4

Verify the devices appear

After rebooting, right-click the speaker icon in the taskbar and open Sound settings. You should now see CABLE Input (VB-Audio Virtual Cable) as a playback device and CABLE Output (VB-Audio Virtual Cable) as a recording device.

⚠️
Don't set CABLE Input as your Windows default playback device

If you set CABLE Input as your default speaker, all your system audio will go through the virtual cable and you won't hear anything from your PC. Only the bot should send audio to it — everything else stays on your normal speakers/headphones.

Configuring the Bot

Open the bot and go to ⚙️ Settings → Audio → Output device. Click the refresh button (↻) if the list is empty. Select CABLE Input (VB-Audio Virtual Cable) from the dropdown and click 💾 Save Settings.

Configuring PCSX2

See the PCSX2 Configuration page for the full walkthrough. In short: in PCSX2, go to Settings → Audio and set the Microphone input to CABLE Output (VB-Audio Virtual Cable).

Testing the Routing

To confirm audio is flowing from the bot to PCSX2 before loading the game:

  1. Connect the bot to your Twitch channel
  2. In PCSX2, open Settings → Audio — there should be a microphone level meter
  3. In your Twitch chat, type yes
  4. The level meter in PCSX2 should spike when the bot plays the audio

If the meter does not move, the output device in the bot is not set to CABLE Input, or PCSX2's microphone input is not set to CABLE Output.

Your Own Microphone for Commentary

Your real microphone for talking to your stream audience is completely separate. It goes through your normal audio interface and OBS/streaming software as usual. The virtual cable only carries the bot's command audio. The two systems do not interfere with each other.

If you also want your own voice to reach the game (for example to test commands yourself), you would need VoiceMeeter to mix both your mic and the bot audio together and route them to PCSX2. This is an advanced setup not covered here.
