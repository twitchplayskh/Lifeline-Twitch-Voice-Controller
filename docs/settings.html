Settings Reference

Every setting in the app explained — what it does, what the default is, and when to change it.

💾

Settings are saved to config.json only when you click 💾 Save Settings. Changes you make are not applied until you save. After saving, the bot applies the new values immediately without needing a restart.

Twitch IRC

SettingDefaultDescription
Channel nameemptyYour Twitch channel name without the # symbol. The bot joins this channel and reads all chat messages.
OAuth tokenemptyYour Twitch IRC token from twitchapps.com/tmi. Displayed as asterisks. Required to connect.

Audio

SettingDefaultDescription
Audio files folderemptyFolder containing your .wav/.mp3/.ogg command audio files. Optional — TTS handles words with no file. See Audio Files.
Output deviceDefaultWhere the bot plays audio. Must be set to CABLE Input (VB-Audio Virtual Cable) for the game to hear commands. See Virtual Audio Cable.
↻ Refresh devices—Re-scans audio devices. Use if you plugged in a new device or VB-Cable was not visible on first launch.

Playback

SettingDefaultDescription
Command cooldown1.5sMinimum seconds between plays of the same command word. Prevents one word being spammed endlessly. Different words are not affected by each other's cooldowns.
Volume1.0Multiplier applied to all audio playback. 1.0 = normal, 2.0 = double, 0.5 = half. If the game is not registering commands, try increasing volume first.

Virtual Controller

SettingDefaultDescription
Enable virtual controlleroffCreates a virtual gamepad using ViGEmBus. Must be ticked for any button presses to work. Requires ViGEmBus driver installed.
Controller typeDS4DS4 (PlayStation) or Xbox 360. PCSX2 usually sees DS4 as a PS2-compatible controller. Switch to Xbox 360 if DS4 fails to initialise.
Mic input buttonCircle ○ (fixed)Always Circle — this cannot be changed. Lifeline uses Circle to activate the microphone. Informational only.
Hold for full audio durationonWhen ticked, Circle stays held from start to finish of the audio clip before releasing. Strongly recommended. See Circle Button Timing.
Delay before press0.00sExtra wait before Circle is pressed. Leave at 0 unless you have a specific reason.
Pause after press0.50sThe most important timing. Circle is held this long before audio starts. The game needs this pause to start listening. See Circle Button Timing.
Hold after audio0.00sExtra time Circle stays held after the audio finishes. Try 0.1–0.2s if you get occasional misses.
Pause after release0.00sDead-time after releasing Circle before the next command can start.
Chat-Triggered Button Commandsall offAssign chat words to PS2 buttons (Square, Cross, Triangle, L1, R1, L2, Start, Select). These press the button without any Circle hold. See Chat Button Commands.
Test Circle timing—Runs through the full press-pause-hold-release sequence without audio. Useful for confirming the virtual controller is working in PCSX2.
Reset to defaults—Resets all timing spinboxes to their default values.

Text-to-Speech

SettingDefaultDescription
Enable TTSoffWhen on, words with no audio file are synthesised via pyttsx3. Recommended — without this, many commands are silently skipped.
Always use TTSoffIgnores all audio files and synthesises everything via TTS. Useful for consistent voice or testing.
Filter hateful / explicit wordsonBlocks slurs and explicit words from ever being spoken. Also blocks chat button trigger words from reaching TTS. Keep this on.
TTS voiceDefaultSAPI voice used for synthesis. Lists all voices installed on Windows. Click ↻ to refresh. Different voices have different recognition rates with the game — experiment.
Speech rate150 wpmWords per minute. Lower = slower and clearer. Try 120–130 if the game misses TTS commands.
Gap between words0.0sPause between individual audio files in a multi-word sequence. Positive = add silence. Negative = trim silence from end of each clip. Does not apply when a sentence is synthesised as one TTS phrase.
Test TTS—Triggers the word "go" through the full TTS pipeline so you can hear the current voice and rate setting.
Reset TTS defaults—Resets rate to 150 wpm and gap to 0.0s.

Commands Tab

The 📋 Commands tab is not part of Settings but is important for customisation:

SectionDescription
Single-word commandsAll 314 built-in single words, shown in blue. Scrollable grid.
Official phrasesAll 91 built-in multi-word phrases, shown in gold. Scrollable.
Custom CommandsText box where you add your own trigger words or phrases, one per line. Multi-word lines are treated as phrases. Click Apply after editing.

config.json

All settings are stored in config.json in the same folder as the bot. It is written atomically — if the app crashes mid-save, the old config is preserved and a backup is made as config.json.corrupted. You can inspect the file in any text editor but editing it by hand is not recommended.
