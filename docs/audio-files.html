Audio Files

Use your own recorded voice clips for commands instead of — or alongside — text-to-speech.

Why Use Audio Files?

The game's voice recognition was tuned to the PS2 USB Headset and human speech patterns. A recorded human voice is more reliably recognised than TTS synthesis, especially for longer or unusual words. If you or someone else records the command words clearly, recognition rates improve significantly.

Audio files and TTS work together — you can have files for the common commands and let TTS handle everything else.

File Naming

The filename must match the command word or phrase exactly (case-insensitive). The bot looks for:

go.wav        ← matches the command "go"
YES.WAV       ← also matches "yes" (case-insensitive)
go back.wav   ← matches the phrase "go back"

Supported formats: .wav .mp3 .ogg .flac .aiff

WAV is recommended — it loads with no decode overhead and avoids any codec issues.

Folder Structure

Put all files in a single folder. Subfolders are not scanned. Example:

C:\lifeline-audio\
  ├── go.wav
  ├── yes.wav
  ├── no.wav
  ├── stop.wav
  ├── check.wav
  ├── walk.wav
  ├── run.wav
  ├── left.wav
  ├── right.wav
  ├── go back.wav
  ├── zoom in.wav
  └── ...

Recording Tips

  • Speak clearly and at a normal pace — do not rush or over-enunciate
  • Record in a quiet room to minimise background noise
  • Use a decent microphone — even a gaming headset is fine
  • Clip each word or phrase tightly — remove long silences at the start and end
  • Normalise the volume so all files are at roughly the same level
  • Mono 44100 Hz WAV is ideal — stereo works but is unnecessary
💡

Audacity (free, audacityteam.org) is excellent for recording and trimming voice clips. Record each word, trim silence at both ends using Effect → Truncate Silence, then export as WAV.

Priority Order

When a command is triggered, the bot resolves audio in this order:

  1. Audio file — if a matching file exists in the folder, it is used
  2. TTS — if TTS is enabled and no file exists, the word is synthesised
  3. Skipped — if neither is available, the command is logged as ! word (no_file) and nothing is spoken

You can override this by enabling Always use TTS in settings, which ignores audio files entirely and synthesises everything.

Setting the Folder

In the bot, go to ⚙️ Settings → Audio → Audio files folder and click Browse… to select your folder. Click 💾 Save Settings.

The folder is cached after first scan — if you add new files to the folder while the bot is running, you do not need to restart. The cache clears automatically when you change the folder path.

Phrase Audio Files

Multi-word phrases can have their own audio files too. Name the file after the full phrase:

go back.wav
zoom in.wav
microphone check.wav
where am i.wav

If a phrase audio file exists, it is played as a single clip rather than splitting into individual words. This sounds much more natural for scenario questions like "what's a philosopher's stone".
