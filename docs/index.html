Lifeline Twitch
Voice Controller

Let your Twitch chat crowd-play Lifeline: Operator's Side (PS2, 2003) by typing voice commands that are spoken to Rio through a virtual microphone.

What Is This?

Lifeline: Operator's Side is a unique PS2 game from Konami (2003) that is controlled entirely by voice. You speak into a microphone and Rio — the character you are guiding through a space station disaster — hears you and responds. There are no directional stick controls for gameplay; the microphone IS the controller.

This program bridges your Twitch chat to the game. Viewers type command words or phrases, and the bot automatically:

1

Detects the command

Scans every chat message for recognised Lifeline words and phrases. Supports 314 single words and 91 official multi-word phrases from the game's FAQ.

2

Holds Circle on a virtual controller

Presses and holds the Circle button on a virtual PS2 controller. In Lifeline, Circle activates the microphone — the game won't listen unless Circle is held.

3

Plays the audio

After a 0.5 second pause (which the game requires before it starts listening), plays the audio file for that command — or synthesises it via text-to-speech if no file exists. The audio is routed through a virtual audio cable so it reaches the game as a microphone input.

4

Releases Circle

Once the audio finishes playing, Circle is released. Rio has heard the command and will respond.

⚠️
Virtual Audio Cable Is Required

This program cannot work without a virtual audio cable. The game listens for a real microphone — the virtual cable makes the bot's audio appear as microphone input to PCSX2. See the Virtual Audio Cable setup guide for full instructions.

How the Microphone Mechanic Works

Understanding this is important before you configure anything. Lifeline uses the PS2 USB Headset microphone. When you press and hold Circle, the game begins listening. You speak your command, then release Circle. The timing between pressing Circle and speaking matters — too soon and the game misses it.

→

The bot replicates this sequence exactly. The 0.5 second pause is the most important setting — it is enabled by default and works for most people. All timings are configurable in the Circle Button Timing page.

Quick Start

If you just want to get running as fast as possible:

  1. Install VB-Cable and reboot
  2. Install ViGEmBus and reboot
  3. Run pip install -r requirements.txt
  4. Run python lifeline_bot.py (or double-click run.bat)
  5. In Settings: enter your Twitch channel + OAuth token, set Output device to "CABLE Input", enable the virtual controller
  6. In PCSX2: set Microphone input to "CABLE Output", assign the virtual controller to Player 1
  7. Click Connect and test with a word like yes

For the full step-by-step with screenshots and explanations, start with the Requirements page.
