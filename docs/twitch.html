Twitch Connection

How to connect the bot to your Twitch channel so it can read chat messages.

How It Works

The bot connects to Twitch using the IRC (Internet Relay Chat) protocol — the same underlying system Twitch uses for all chat. It reads every message in your channel and scans for recognised command words. It does not post messages to chat (it is read-only).

To connect, it needs two things: your channel name and an OAuth token that proves it has permission to read your chat.

Getting Your OAuth Token

ℹ️

An OAuth token is a password-like string that lets an application access your Twitch account without knowing your real password. This token only grants chat-read permission — it cannot stream on your behalf, change your settings, or do anything else.

1

Go to twitchapps.com/tmi

Open twitchapps.com/tmi in your browser. This is a simple Twitch-authorised tool specifically for generating IRC tokens.

2

Connect with Twitch

Click the Connect with Twitch button. You will be redirected to Twitch's login and authorisation page. Log in with the account you want the bot to use (usually your own streaming account).

3

Copy the token

After authorising, you will be shown a token that looks like oauth:abcdefghij1234567890abcdefghij. Copy the entire string including the oauth: prefix.

4

Paste into the bot

In the bot, go to ⚙️ Settings → Twitch IRC → OAuth token and paste the token. The field shows asterisks to keep it hidden — this is normal.

⚠️
Keep your token private

Treat the OAuth token like a password. Do not share it, paste it into stream, or commit it to a public GitHub repository. If it is ever exposed, revoke it at twitch.tv/settings/connections and generate a new one.

Channel Name

Enter your Twitch channel name in the Channel name field. This is just your username — do not include the # symbol. For example if your channel is twitch.tv/mychannel, enter mychannel.

The bot can connect to any public Twitch channel, not just your own. If you want to monitor a different channel, enter that channel's name instead.

Connecting

After saving settings, go to the 🎮 Live Feed tab and click ▶ Connect.

  • The indicator shows ⬤ Connecting… in orange while the IRC handshake happens
  • It turns ⬤ Live in green once successfully joined
  • Chat messages appear in the left panel in real time
  • Command words are highlighted in gold in the chat panel

To disconnect, click ■ Disconnect. To reconnect to a different channel, disconnect first, change the channel name in Settings, save, then reconnect.

The Chat Log

The left panel on the Live Feed tab shows all chat messages as they arrive. Messages containing recognised command words have those words highlighted in gold so you can see at a glance what the bot is picking up. The right panel shows only the commands that actually fired (with Circle timing details).

The 🗑 Clear Log button wipes both panels without disconnecting.

Cooldown

The cooldown setting (under Settings → Playback → Command cooldown) controls the minimum number of seconds that must pass before the same command can fire again. This prevents a single word from being spammed endlessly. The default is 1.5 seconds.

The cooldown applies per command word — different words can fire simultaneously regardless of cooldown.
