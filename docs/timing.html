Using the Bot

Circle Button Timing

The most important tuning parameter. Getting this right is the difference between Rio hearing every command and Rio hearing nothing.

The Sequence

Lifeline requires a specific sequence to register a voice command. This is how real players use the game with a physical microphone, and the bot replicates it exactly:

PRESS ○
Circle held
→
0.50s pause
game starts listening
→
AUDIO plays
full duration
→
RELEASE ○
done

The 0.5 second pause between pressing Circle and speaking is critical. The game's voice recognition system needs this time to initialise after Circle is pressed. Speak too soon and it misses the command entirely — even if the audio is loud and clear.

The Four Timing Settings

1. Delay Before Press

An extra wait added before Circle is pressed. Default is 0.0s. Leave this at zero unless you have a specific reason to delay — for example if a previous command needs more time to fully complete before the game is ready to listen again.

2. Pause After Press ← the important one

How long Circle is held before the audio starts playing. Default: 0.50s. This is the timing that community experience shows works best. If the game is not responding, this is the first thing to adjust — try 0.7s or 1.0s. If commands are registering but very slowly, you can try reducing to 0.3s.

3. Hold After Audio

Keeps Circle held for this many extra seconds after the audio finishes before releasing. Default is 0.0s. Some players find that holding Circle slightly longer after speaking helps — try 0.1s–0.2s if you're having intermittent misses.

4. Pause After Release

Dead-time between releasing Circle and the next command being allowed to start. Default is 0.0s. Increase this if rapid consecutive commands seem to confuse the game.

Hold for Full Audio Duration

When ticked (the default), Circle is held continuously from the start of the sequence until the very end of the audio file, then released. This is the correct behaviour — the game expects Circle to be held for the entire duration of speech.

When unticked, Circle is released as soon as the audio begins playing. This is mainly useful for testing and is not recommended for normal use.

Multi-Word Sentences

For sentences like "go to the table", Circle is pressed once at the start and released once at the end — after all words have finished playing. Circle is never released between individual words.

PRESS ○
→
0.50s
→
"go"
→
"to the table"
all words
→
RELEASE ○

Live Timeline Preview

The settings panel shows a live text preview of the full sequence as you adjust sliders:

[PRESS Circle]  →  pause 0.50s  →  [AUDIO...full length]  →  [RELEASE Circle]

This updates instantly when you change any value so you can see the effect before testing.

Testing

The Test Circle timing button runs through the full sequence without playing any audio. Watch PCSX2's controller input display — you should see the Circle button register for the duration of the test. The command log will show:

[Test] pre=0.00s hb=0.50s ha=0.00s rd=0.00s
● Circle HELD
[audio would play here]
○ Circle released
done
