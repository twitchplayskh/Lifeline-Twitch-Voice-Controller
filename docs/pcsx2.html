PCSX2 Configuration

How to configure PCSX2 to use the virtual audio cable as its microphone and the virtual controller as Player 1.

ℹ️

These instructions are written for the PCSX2 Qt nightly build (v1.7+). The menu locations may differ slightly in older PCSX2 versions. The nightly build from pcsx2.net is recommended.

Step 1 — Microphone Setup

This tells PCSX2 to treat the virtual cable's output as a microphone input, which is what the game will read.

1

Open PCSX2 Settings

In PCSX2, go to Settings → Audio (or Config → Audio Settings in older versions).

2

Find the Microphone / Recording Device setting

Look for a field labelled Microphone, Recording Device, or Input Device. In the nightly Qt build this is under the SPU2 section.

3

Select CABLE Output

Set this to CABLE Output (VB-Audio Virtual Cable). This is the receiving end of the virtual pipe — audio played to CABLE Input by the bot comes out here as a mic signal.

4

Set microphone volume

Make sure the microphone volume slider is turned up — if it is at zero the game receives silence even though audio is flowing through the cable. Start at 100% and adjust if the game reacts inconsistently.

Step 2 — Controller Setup

This assigns the virtual DS4/Xbox controller to Player 1 so the bot can press Circle.

1

Open Controller Settings

Go to Settings → Controllers.

2

Enable the virtual controller in the bot first

Before PCSX2 can see the virtual controller, it must be created. In the Lifeline bot, tick Enable virtual controller in Settings and save. The virtual controller now exists as a Windows device.

3

Select the virtual controller for Port 1

In PCSX2's controller settings, look at Port 1 (Player 1). In the device list you should see the virtual controller — it will be listed as a DualShock 4 or Xbox 360 controller depending on which mode you chose. Select it.

4

Map the buttons

PCSX2 usually auto-maps standard controllers. If not, manually map at minimum: Circle, Square, Cross, Triangle, L1, R1, L2, Start, Select. The D-Pad can be mapped to the left stick or D-Pad of the virtual controller.

⚠️
Keep the bot running while PCSX2 is open

The virtual controller only exists while the bot is running. If you close the bot, PCSX2 loses the controller. Always launch the bot first, enable the controller, then launch PCSX2.

Step 3 — USB Headset Emulation

Lifeline specifically checks for the PS2 USB Headset device. In PCSX2 you may need to enable USB device emulation to make the game recognise the microphone.

1

Go to USB Settings

In PCSX2, go to Settings → USB.

2

Assign USB port 1 as Headset

Set USB Port 1 to Headset or PS2 Mic. The exact label varies by PCSX2 version.

3

Set the headset's mic input

In the headset device settings, set the microphone source to CABLE Output (VB-Audio Virtual Cable) — the same device you set in the audio settings.

Verifying Everything Works

Load Lifeline in PCSX2. When the game's microphone check screen appears (or any point where Rio is waiting for a voice command):

  1. Type yes in your Twitch chat
  2. Watch the bot's command log — you should see ● Circle HELD then ▶ yes then ○ Circle released
  3. Rio should respond as if you said "yes" into a real microphone

If Rio does not respond, check the Troubleshooting page.
