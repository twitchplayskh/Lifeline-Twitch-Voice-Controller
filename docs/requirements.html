Requirements

Everything you need to install before the bot will work — and why each piece matters.

🛑
Install in order and reboot when told

VB-Cable and ViGEmBus both install kernel-level Windows drivers. If you skip the reboots, the drivers will not be active and the bot will fail silently in ways that are difficult to debug.

Required Software

1. Python 3.8 or newer

The bot is written in Python. If you do not have Python installed:

  1. Go to python.org/downloads
  2. Download the latest 3.x release for Windows
  3. Run the installer — on the first screen, tick "Add Python to PATH" before clicking Install Now
  4. To verify, open Command Prompt and type python --version
ℹ️

If you already have Python but the python command doesn't work, try python3 instead. If neither works, Python is not on your PATH — reinstall and tick the "Add to PATH" checkbox.

2. VB-Cable — Virtual Audio Cable

This is the most important dependency. The game listens for a real microphone. VB-Cable creates a virtual audio device that lets the bot's audio output appear as a microphone to PCSX2 and the game.

Without this, the game will never hear anything the bot plays.

  • Download from vb-audio.com/Cable — it is free (donation-ware)
  • Run VBCABLE_Setup_x64.exe as Administrator (right-click → Run as administrator)
  • Reboot your PC after installation

After rebooting you should see two new audio devices in Windows Sound settings: CABLE Input and CABLE Output. See the Virtual Audio Cable page for the full routing setup.

3. ViGEmBus Driver

This is a Windows driver that lets software create virtual Xbox 360 and DualShock 4 controllers. The bot uses it to hold the Circle button during voice commands.

  • Go to github.com/nefarius/ViGEmBus/releases
  • Download the latest ViGEmBus_Setup_x64.exe
  • Run the installer
  • Reboot your PC after installation

4. PCSX2 — PS2 Emulator

You need a PS2 emulator to run Lifeline. PCSX2 is the standard choice.

  • Download from pcsx2.net/downloads
  • The nightly build (Qt version) is recommended for best compatibility
  • You will also need a PS2 BIOS file — this comes from your own PS2 console

5. Lifeline: Operator's Side

You need your own copy of the game. It was released in Japan as Operator's Side and in North America as Lifeline. Both versions work. Create an ISO from your own disc.

Python Dependencies

These are installed automatically when you run pip install -r requirements.txt (or double-click run.bat):

PackagePurposeNotes
sounddevicePlays audio through the selected output deviceRoutes to VB-Cable
soundfileReads .wav, .mp3, .ogg, .flac, .aiff files
numpyResamples audio to match device's native sample ratePrevents "Invalid sample rate" errors
vgamepadCreates virtual DS4/Xbox controller, presses CircleRequires ViGEmBus driver
pyttsx3Text-to-speech synthesisUses Windows SAPI voices
better-profanityFilters explicit words before TTSOptional but recommended

Hardware

No special hardware is required. The bot uses entirely virtual devices — no physical microphone, no physical PS2 controller.

If you are streaming, your own microphone for commentary goes through your normal audio setup and is completely separate from the virtual cable used by the bot.
